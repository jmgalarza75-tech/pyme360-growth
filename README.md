# Pyme360 Public Website

This repository is deployed to Hostinger for the public Pyme360 website.

Hostinger settings:

- Branch: `main`
- Root directory: `public_html`
- Public homepage: `index.html`

Files required for the public site:

- `index.html`
- `assets/pyme360-public.css`
- `assets/pyme360-public.js`

Do not upload private operations files such as `.env`, internal dashboards, local scripts, or API credentials.
