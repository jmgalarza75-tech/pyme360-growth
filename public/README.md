# Pyme360 Public Website

This folder contains the public marketing website for Pyme360.

Upload the contents of this `public` folder to Hostinger's public web root, usually `public_html`.

Files to upload:

- `index.html`
- `assets/pyme360-public.css`
- `assets/pyme360-public.js`

Do not upload internal workspace files such as:

- `.env`
- `dashboard.html`
- `buscador.html`
- `pipeline.html`
- `newsletter.html`
- `mailing_engine.js`

Those files belong to the private intranet and operations system.
